# Conclusions

One folder per level. Each level is written up twice:

| File | For whom | Style |
|---|---|---|
| `paper.md` | reviewers, the final paper | Academic: abstract, method, results, limitations, references |
| `explained.md` | us, while learning | Plain language: what we did, why, what each number means, what surprised us |

Write `explained.md` **first**. If something can't be explained simply, we don't
understand it well enough to put it in the paper.

Start a new level by copying `_template/` to `level_N/`.
